# 赛琳雷恩世界库 · 只读镜像站

本仓库是《赛琳雷恩》世界观数据库的**对外只读镜像**，由作者本机的
`tools/build_site.py` 从发布快照生成，全部内容可整体重建。

- **这不是正本。** 正本在作者本机，本仓库只是印刷品。
- **这里不含小说原文**，只含设定条目。
- 本仓库内容为脚本生成，**请勿直接编辑**；任何改动都会被下一次同步覆盖。

## 给 AI 的入口

先读 `llms.txt`，再按它指的路径查。

**如果你是网页端 AI、要跟作者本机的 AI 分工协作，先读 `handbook/` 目录里的交接书。**
那里写清了外部 AI 负责什么、本机 AI 负责什么、提案该用什么格式提。

## 目录

| 路径 | 内容 |
|---|---|
| `llms.txt` | 给 AI 的说明书 |
| `meta.json` | 库版本与全部产物 sha256 |
| `index.md` / `index.json` | 199 条实体目录 |
| `entities/` | 每个实体一页（`.md` 人读 / `.json` 机器读） |
| `eras/` | 三个时代分册（历史 / 主线 / 后日谈） |
| `relations.json` / `timeline.json` | 关系表 / 时间线 |
| `packs/` | **创作包库**：写小说用的材料包，已按时代+时间点+受众隔离 |
| `review/` | 审查分册（34 册）+ 一页纸 + 全量基线 |
| `handbook/` | **给外部 AI 的交接书**（分工、提案格式、铁律） |

## 引用规矩

引用本库结论时必须带上 `meta.json` 里的源库 sha256，禁止写没有对象的结论。
